# Outlier

- Official repository: daemnapps/outlier
- License: MIT
- Offline: Partial. The toolkit files are local/plain text, but the documented production workflow depends on external model and research services.
- AI required: Yes for the main generative-marketing workflow.
- Internet/API: Internet is required for Claude/Cowork, Google Gemini, and optional competitor/media services.
- API key: Anthropic and Google Gemini are required for the documented core workflow; Higgsfield and AdPlexity are optional.
- Local/self-hosted: The toolkit and brand/prompt files are local, but the AI generation/research services are external.
- Basic non-AI workflow: review and edit the local brand folder, prompts, teardown templates and briefs as plain text without sending data to a service; full generation requires the external AI workflow.
- Runtime prerequisites: no software installation is required by the repository; its README describes Claude/Cowork, Google Drive and external media/model services as the operating environment.
- Limitation: the repository describes the tools as live experiments rather than a maintained product; code is free, but model/service usage can cost money.
- Source verified: official GitHub repository/documentation.

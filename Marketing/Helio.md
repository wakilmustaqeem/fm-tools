# Helio

- Official repository: achref-soua/helio
- License: AGPL-3.0
- Offline: Partial.
- AI required: No for the core CRM/marketing automation; AI is optional but integrated.
- Internet/API: Self-hosted core runs locally, while email/SMS/WhatsApp and external AI providers require network access.
- API key: Required for selected external providers/channels; local model servers can avoid cloud AI keys.
- Local/self-hosted: Yes; Docker-based installation is documented.
- Basic local workflow: manage contacts/deals, segments, journeys, analytics and backups on your own infrastructure; connect only the channels/providers you approve.
- Limitation: connected messaging and external integrations are not offline.
- Source verified: official GitHub repository.

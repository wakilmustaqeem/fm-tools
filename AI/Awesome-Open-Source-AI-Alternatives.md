# Awesome Open Source AI Alternatives

- Official repository: JeevaVenkidu/awesome-open-ai-alternatives
- License: CC BY 4.0 for the directory contents; individual projects retain their own licenses.
- Type: curated directory of open-source/local alternatives covering LLMs, agents, RAG, coding, image, video, voice and local deployment.
- Offline: Varies by project; the list includes self-hosted/local options.
- AI required: Yes at the listed-project level.
- API key: Varies; local deployments can avoid cloud-provider keys.
- Local/self-hosted: Many listed projects support it, but each project must be verified separately.
- Basic non-cloud workflow: select a candidate, then verify its own license, model terms, hardware requirements and local deployment instructions before adoption.
- Internet boundary: cloud models/services need internet; local inference can operate without cloud access after required model files are available.
- Limitation: “open weights” and “source available” are not automatically equivalent to OSI-approved open-source software.
- Source verified: official GitHub repository; README updated July 2026.

## Verification policy
- Verify the official/original repository before adding a tool.
- Record license, current status, local/self-hosted requirements, and whether an API key is required.
- Prefer free/open-source options; clearly mark tools with optional paid services.
- No destructive installation or project changes without approval and verification.

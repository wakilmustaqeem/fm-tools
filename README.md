# FM Tools Bank

Central catalog for verified free and open-source tools used across FM projects.

## Categories
- SEO
- AI
- Design
- Writing
- Developer
- Productivity
- Marketing
- Video
- Audio
- General / Awesome Lists

## Verification policy
- Verify the official/original repository before adding a tool.
- Record license, current status, local/self-hosted requirements, and whether an API key is required.
- Prefer free/open-source options; clearly mark tools with optional paid services.
- No destructive installation or project changes without approval and verification.

## Project mapping
- Biztoolkit: SEO, design, marketing
- InvoiceFlow: SEO, developer, design
- AI Faceless YouTube: AI, video, audio, developer
- FM Home: governance and tool registry

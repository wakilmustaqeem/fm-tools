# Graphite

- Official repository: GraphiteEditor/Graphite
- License: dual Apache-2.0 / MIT for source code, unless otherwise noted.
- Type: free/open-source 2D vector and raster graphics editor/engine with nondestructive layer and node-based procedural workflows.
- Offline: Partial. Core source/build can run locally, while the hosted editor, online assets and web-connected services require network access.
- AI required: No for core graphics editing; AI is not required to create or edit artwork.
- API key: Not required for core editing.
- Local/self-hosted: Yes, via the open-source source/build workflow; the project also provides a hosted web experience.
- Basic non-AI workflow: open the editor, create vector/raster artwork, use layers and procedural node graphs, edit nondestructively, then export the resulting work using the supported local/web workflow.
- Runtime prerequisites: source development is Rust-based and the repository provides build/development instructions; the project is currently in alpha.
- Internet boundary: hosted web use and online resources need internet; local source builds can reduce this dependency.
- Limitation: alpha status means features and workflows are still under active development; exact local build requirements can change upstream.
- Source verified: official GitHub repository and current README/license information.

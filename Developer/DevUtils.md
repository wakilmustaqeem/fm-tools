# DevUtils

- Official repository: nadimtuhin/devutils
- License: MIT.
- Type: privacy-first browser-based developer utility suite with 35+ formatters, converters, encoders, decoders and text/security tools.
- Offline: Yes after the app/assets are available locally; the project states processing happens in the browser and works without internet once loaded.
- AI required: No.
- API key: Not required.
- Local/self-hosted: Yes; the repository documents local Node/pnpm development.
- Basic non-AI workflow: run the local app, then use JSON/SQL/YAML formatters, Base64/CSV/JSON converters, JWT/certificate tools, regex/cron/timestamp utilities, diff and Markdown/HTML previews directly in the browser.
- Runtime prerequisites: Node.js with pnpm; the documented local setup is `git clone`, `pnpm install`, then `pnpm dev`.
- Internet boundary: initial dependency/repository download needs internet; core processing is local once the application/assets are available.
- Limitation: browser-local processing does not mean external network tools exist; capabilities are limited to the tools included in the project.
- Source verified: official GitHub repository, current README and license.

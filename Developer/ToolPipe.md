# ToolPipe

- Official repository: Ithiel-Labs/toolpipe
- License: MIT.
- Type: open-source browser developer-tool suite plus hosted REST API and optional MCP server.
- Offline: Partial. Browser/static utilities can be used locally after the app/assets are available; hosted REST/MCP endpoints require internet.
- AI required: No for core utilities; AI-powered code review is optional.
- API key: Not required for the documented free API tier.
- Local/self-hosted: Source available; individual endpoint dependencies must be checked before offline deployment.
- Basic non-AI workflow: use local JSON, regex, JWT, SQL, QR, encoding, timestamp and similar utilities; use hosted endpoints only when network access is acceptable.
- Runtime prerequisites: browser for the web/static tools; source-based local use depends on the repository's current build/development setup.
- Internet boundary: DNS/WHOIS/SSL/URL/network lookups inherently need network; the hosted REST API and MCP endpoint are remote services.
- Limitation: not every tool can be offline because network inspection tools depend on external targets; hosted service pricing includes paid tiers even though the free tier is available.

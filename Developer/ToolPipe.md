# ToolPipe

- Official repository: Ithiel-Labs/toolpipe
- License: MIT
- Offline: Partial — many browser utilities can be used locally, but hosted REST APIs require internet.
- AI required: No for the core utilities; AI-powered code review is an optional feature.
- Internet/API: Hosted API endpoints require internet; local/static tools can be run from the source.
- API key: The repository states its free API tier needs no API key.
- Local/self-hosted: Source is available; verify individual endpoint dependencies before offline use.
- Basic non-AI workflow: use JSON, regex, JWT, SQL, QR, encoding, timestamp and similar developer utilities; keep sensitive data local when using local/static tools.
- Source verified: official GitHub repository.

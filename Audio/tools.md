# Audio Tools Bank

## VoiceStudio
- Official repository: niaodian/voicestudio
- License: AGPL-3.0 (optional engines/models may have their own licenses).
- Offline: Yes for the core local workflow after required models are available locally.
- AI required: No cloud AI service is required; the core TTS/ASR/voice workflows use local engines/models.
- Internet/API: Initial installation/model downloads may require internet; remote workers and remote APIs are optional.
- API key: Not required for the core local workflow.
- Local/self-hosted: Yes.
- Basic non-cloud workflow:
  1. Install VoiceStudio for the supported desktop platform.
  2. Let the required local model(s) download once.
  3. Select a local TTS/ASR engine.
  4. Use local transcription, dictation, synthesis, dubbing or audiobook workflows.
  5. Keep projects and outputs on the machine.
- Limitation: Actual language/quality and hardware requirements vary by selected engine/model.
- Source verified: official GitHub README.

## Rule
This matrix is a planning aid, not a substitute for each tool's official documentation. A **catalog** entry can be offline-capable while a specific feature still requires internet, an API, or a model download.

## Safe FM workflow
1. Choose the tool.
2. Read its tool-specific record.
3. Check **Offline / AI / Internet / API key** fields.
4. Test on sample data or a copy.
5. Only then use it on an FM production project.

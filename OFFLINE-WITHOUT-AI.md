# Offline / Without-AI Use Guide

This guide is for using FM Tools without an AI service.

## Standard method

1. Prefer the tool's official GitHub repository and documentation.
2. Download the project and read its README and requirements.
3. Install only documented dependencies.
4. If a local/offline mode exists, use it and keep data local.
5. If an API key or cloud account is required, mark that feature as **not offline**.
6. Test on a copy/sample project before production use.
7. Keep reports and exports in the relevant FM project folder.
8. Do not upload private project data to third-party services without approval.

## Required record for every tool

- **Offline:** Yes / Partial / No / Unknown
- **AI required:** Yes / No / Optional
- **Internet required:** Yes / No / Partial
- **API key:** Required / Optional / Not required / Unknown
- **Local/self-hosted:** Yes / No / Partial
- **Basic non-AI workflow:** documented manual/local steps
- **Limitations:** what cannot work offline

## Important

Open source does **not** automatically mean fully offline. Free does **not** automatically mean no account or API key. AI features are recorded separately from normal non-AI features.

Tool-specific offline instructions will be added after verification of each official repository and documentation.

# Awesome Selfhosted

- Official repository: awesome-selfhosted/awesome-selfhosted
- Type: curated directory of Free Software network services and web applications that can be hosted on your own server(s).
- License: CC BY-SA 3.0 for the list.
- Offline: Varies by individual project; self-hosting does not automatically mean fully offline.
- AI required: Varies by individual project.
- Internet/API: Varies. Some services are network applications by design and may depend on external services.
- API key: Varies by individual project.
- Local/self-hosted: Yes at the directory level; each selected project has its own deployment requirements.
- Basic non-AI workflow: search the directory by category, select a candidate, inspect its own license/dependencies/maintenance/network requirements, deploy locally or on owned infrastructure, then test before production.
- Limitation: the directory is a discovery catalog, not a single runtime. Individual projects can have separate licenses, dependencies and third-party-service requirements; use the upstream project record before adoption.
- Source verified: current official GitHub repository/project site.

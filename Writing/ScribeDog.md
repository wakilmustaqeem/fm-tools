# ScribeDog

- Official repository: snooky234/scribedog
- License: MIT
- Offline: Yes.
- AI required: No for ordinary Markdown writing/editing/export; AI is optional and can run locally.
- Internet/API: Not required for ordinary local writing. Optional update checks can be disabled. Local AI uses Ollama, Jan.ai or LM Studio.
- API key: Not required for local/non-AI use; cloud AI is optional and uses your own provider key.
- Local/self-hosted: Yes; desktop and self-hosted server editions.
- Basic non-AI workflow: open a local folder, write/edit Markdown in WYSIWYG mode, organize linked notes, then export to PDF/DOCX/ODT/HTML.
- Privacy: files stay local; no telemetry according to the project README.

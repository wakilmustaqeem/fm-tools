# AppFlowy

- Official repository: AppFlowy-IO/AppFlowy
- License: AGPL-3.0 for the open-source AppFlowy client repository.
- Offline: Yes / Partial depending on workflow. The desktop app can be installed locally and personal data can be controlled locally; collaboration, sync and hosted/self-hosted server features require network.
- AI required: No for core notes, projects, wikis and task-management workflows; AI features are optional.
- Internet/API: Basic local work can be performed without cloud AI; sync, collaboration and connected services require network.
- API key: Not required for core non-AI local use; AI/provider integrations may require their own credentials.
- Local/self-hosted: Yes for the open-source client; current AppFlowy self-hosted server offerings have separate licensing, including a commercial self-hosted fork, so do not treat all server components as AGPL.
- Basic non-AI workflow: install the desktop client, create local pages/projects/tasks, work on notes and wikis, and keep data under your control; enable sync/collaboration only when needed.
- Runtime prerequisites: prebuilt desktop/mobile releases are available; source development uses Flutter and Rust with OS-specific development instructions.
- Limitation: the AppFlowy client is AGPL-3.0, while current self-hosted cloud/server components may be under separate commercial terms; verify the exact component license before deployment.
- Source verified: official AppFlowy GitHub repository and licensing documentation.

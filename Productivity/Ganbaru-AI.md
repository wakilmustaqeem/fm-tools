# Ganbaru AI

- Official repository: opengrimoire/ganbaru-ai
- License: AGPL-3.0
- Offline: Yes / local-first for core productivity features after the application is installed.
- AI required: No; AI is explicitly opt-in.
- Internet/API: Core productivity data/features are local; internet may be needed to download releases, dependencies or optional integrations.
- API key: Not required for core non-AI use.
- Local/self-hosted: Yes; desktop releases are documented for Windows 10/11 and Linux. macOS and mobile builds are not currently available.
- Basic non-AI workflow: use the local anti-procrastination, focus and anti-doomscrolling features with AI disabled.
- Runtime prerequisites: prebuilt releases are available; source is Svelte/Rust-based.
- Limitation: the project explicitly warns that it is under heavy development and unstable.
- Source verified: official GitHub repository/documentation.

# CoWork OS

- Official repository: CoWork-OS/CoWork-OS
- License: MIT
- Offline: Partial.
- AI required: No for the shell/workspace itself; AI features require a compatible local model or provider.
- Internet/API: Local models can avoid cloud APIs, while connected providers/services require internet.
- API key: Optional for supported cloud providers; local models can avoid provider API keys.
- Local/self-hosted: Yes; desktop app supports Windows 10/11 and macOS 13+ according to current documentation.
- Basic non-AI workflow: use the GUI workspace, files, terminal, browser and local artifacts without committing to a CoWork subscription.
- Limitation: provider eligibility, model limits and usage charges are controlled by the selected AI provider.
- Source verified: official GitHub repository/documentation.

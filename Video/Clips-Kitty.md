# Clips Kitty (formerly Clips Studio)

- Official repository: ColinGPT9/clips-studio
- License: AGPL-3.0
- Offline: Yes after the required local model/runtime assets are installed.
- AI required: Yes for automatic clip detection, transcription, tracking and AI editing; these run locally.
- Internet/API: Initial model downloads/setup may require internet. Core processing can run locally.
- API key: Not required for local clipping. Optional YouTube publishing uses your own Google/YouTube API credentials.
- Local/self-hosted: Yes; Windows installer, source and Docker options are documented.
- Basic local workflow: import/local video, run local analysis, review generated vertical clips and captions, edit, then export.
- Note: The project was renamed from Clips Studio to Clips Kitty; the repository remains clips-studio.

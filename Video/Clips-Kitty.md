# Clips Kitty (formerly Clips Studio)

- Official repository: ColinGPT9/clips-studio
- License: AGPL-3.0
- Offline: Yes after required local model/runtime assets are installed.
- AI required: Yes for automatic clip detection, transcription, tracking and AI editing; these run locally.
- Internet/API: Initial model downloads/setup may require internet. Core processing can run locally.
- API key: Not required for local clipping; optional YouTube publishing uses the user's own Google/YouTube API credentials.
- Local/self-hosted: Yes; Windows installer, source and Docker options are documented.
- Basic local workflow: import local video, run local analysis, review generated vertical clips/captions, edit, export, and keep publishing/manual upload separate.
- Runtime prerequisites: current release notes target Windows 10/11 64-bit with about 20 GB free space and strongly recommend an NVIDIA GPU; the local language model downloads on first launch.
- Limitation: current release is alpha-focused on IRL/chatting, podcasts, vlogs and interviews; the project says gaming, split-screen and reaction videos are not yet supported reliably. Installer is not code-signed and Windows may warn.
- Source verified: official GitHub repository/documentation.

# Video Tools Bank

## OpenReel Video
- Official repository: Augani/openreel-video
- License: MIT
- Offline: Yes — runs client-side in the browser; it can also be run locally.
- AI required: No for core video editing.
- Internet/API: Not required for the core editing workflow once the app is available locally; browser/local setup requires the project dependencies.
- API key: Not required for core editing.
- Local/self-hosted: Yes.
- Basic non-AI workflow:
  1. Open the editor or run the repository locally.
  2. Import video/audio/images.
  3. Edit the multi-track timeline, text, graphics, audio and color.
  4. Preview and export locally.
- AI limitation: Some optional features such as AI upscaling/highlight extraction are separate from the basic non-AI workflow.
- Source verified: GitHub README/release information.
